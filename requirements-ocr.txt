# Optional OCR backend for the OCRAnalyzer detector seam.
#
# The core pipeline does NOT need these. Without them a page with no text layer
# fails the gate exactly as before, which is still a documented outcome rather
# than a crash.
#
# Tesseract loads no Python ML framework into the process: ~1.8 GB RSS for
# EasyOCR and ~950 MB for PaddleOCR against tens of MB here, plus 8-20 s of
# cold start. That is the §24 argument — runtime footprint, not download size.
# Both alternatives are likely more accurate on Bengali, which is the trade.
#
#   pip install -r requirements.txt -r requirements-ocr.txt
#
# The engine itself is not a pip package and must be installed separately,
# along with one language file per script you need:
#
#   Windows:  winget install UB-Mannheim.TesseractOCR
#   Debian:   apt install tesseract-ocr tesseract-ocr-ben tesseract-ocr-ara
#   macOS:    brew install tesseract tesseract-lang
#
# The Windows installer ships only the languages you tick, and does not add
# itself to PATH — the detector probes the standard location, so that part is
# handled. For a language it did not install, drop the file somewhere and point
# TESSDATA_PREFIX at it rather than needing admin rights on Program Files:
#
#   curl -L -o .tessdata/ben.traineddata \
#     https://github.com/tesseract-ocr/tessdata_best/raw/main/ben.traineddata
#   export TESSDATA_PREFIX="$PWD/.tessdata"
#
# tessdata_best over tessdata_fast: measured 0.987 on clean Bengali, and the
# speed difference is irrelevant next to the cost of being wrong.

pytesseract>=0.3.10
pillow>=10.0
